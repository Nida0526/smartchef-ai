# SmartChef AI — Demo Login Accounts

These accounts are created automatically every time the backend starts
(in `backend/seedDemoUser.js`) and can be used to log in on any deployment.

| Name        | Email               | Password      |
|-------------|---------------------|---------------|
| Demo Chef   | `demo@smartchef.ai` | `smartchef123` |
| Guest User  | `guest@smartchef.ai` | `guest1234`   |

> Note: the database is in-memory by default, so accounts you register yourself
> reset on restart — but these seeded demo accounts are always available.
